Frontend quick-run
=================

This folder contains the frontend Next.js application in the `roadmap` subfolder.

Commands (from project root):

```bash
# run dev server for the frontend
cd Frontend
npm run dev

# install dependencies for the roadmap app
npm run install-roadmap
```

Notes:
- The real Next app files (app/, package.json, public/, etc.) live in `Frontend/roadmap`.
- If you prefer to run the app directly from `Frontend/roadmap`, `cd Frontend/roadmap && npm run dev` works too.
